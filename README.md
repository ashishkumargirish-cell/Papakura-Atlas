# Papakura History Atlas

A static webpage prototype using source-attributed factual historical entries.

## Run locally
Open `index.html` in a browser.

## Put it online — easiest option: GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new repository, e.g. `papakura-history-atlas`.
3. Upload `index.html` to the repository root.
4. In GitHub open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then **Save**.
7. GitHub will give you a public `github.io` web address.

## Other easy options
- Netlify: drag the project folder into Netlify's deploy area.
- Cloudflare Pages: connect the GitHub repository and deploy it as a static site.
- Vercel: import the GitHub repository and deploy it as a static site.

No server or database is required for this prototype.
